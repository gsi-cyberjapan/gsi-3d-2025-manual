# 設定

地図上の各種表示を切り替えます。

![設定メニュー](/images/settings-menu.png)

**表示**

| 名称 | 説明 |
|---|---|
| 中心十字線 | 地図中心の十字マークの表示／非表示を切り替えます。 |
| 広域図 | 広域図の表示／非表示を切り替えます。 |
| グリッド表示 | グリッド表示メニューを表示します。 |

**操作**

| 名称 | 説明 |
|---|---|
| クリックで移動 | クリックで移動するかどうかを切り替えます。ONにした場合、地図上をクリックするとその場所が地図の中心にくるように移動します。 |

## グリッド表示メニュー

| 名称 | 説明 |
|---|---|
| 経緯度グリッド | 経緯度グリッドの表示／非表示を切り替えます。 |
| UTMグリッド | UTMグリッドの表示／非表示を切り替えます。 |
| タイル座標 | タイル座標の表示／非表示を切り替えます。 |
| 地域メッシュ | 地域メッシュの表示／非表示を切り替えます。 |
| 図郭 | 図郭の表示／非表示を切り替えます。ズームレベル5以上9未満では20万分1、9以上12未満では5万分1、12以上では2万5千分1図郭を表示します。 |
