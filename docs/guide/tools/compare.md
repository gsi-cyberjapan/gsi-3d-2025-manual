# 並べて比較・重ねて比較

## 並べて比較

地図を2画面表示します。サイドバーの「表示モード」から「並べて比較」を選択します。

![並べて比較](/images/compare-side.png)

- 2画面を解除するには、サイドバーの「表示モード」から「通常」を選択します。
- 左右画面の連動のON/OFFを切り替えます。連動をONにすると、地図移動が左右の画面で連動します。

## 重ねて比較

地図を重ねて比較します。サイドバーの「表示モード」から「重ねて比較」を選択します。

![重ねて比較](/images/compare-overlay.png)

- 比較を解除するには、サイドバーの「表示モード」から「通常」を選択します。
- ツマミをドラッグし、左右画面の表示領域の境目を移動します。
