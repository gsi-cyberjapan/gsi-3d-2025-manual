# その他

その他の機能を利用するためのメニューを表示します。

![その他メニュー](/images/others-menu.png)

| 名称 | 説明 |
|---|---|
| 地理院地図で見る | 現在表示している場所を地理院地図で開きます。 |

**外部サービスで見る**

| 名称 | 説明 |
|---|---|
| いつもNAVI | 現在表示している場所をいつもNAVIで開きます。 |
| Mapion | 現在表示している場所をMapionで開きます。 |

**ツール**

| 名称 | 説明 |
|---|---|
| 場所情報コード | 場所情報コードの説明ページ（国土地理院サイト）を開きます。 |
| 等距圏 | 等距圏の表示／非表示を切り替えます。 |
| 方位線 | 方位線の表示／非表示を切り替えます。 |
| 磁北線 | 磁北線の表示／非表示を切り替えます。 |

## 等距圏 {#equidistance}

等距圏の表示／非表示を切り替えます。等距圏は、地球が回転楕円球であることを考慮した、指定した地点からの等しい距離を表す円です。

![等距圏](/images/equidistance.png)

| 設定項目 | 説明 |
|---|---|
| 間隔 | 同心円の間隔を指定します（m / km 単位） |
| 本数 | 表示する同心円の本数を指定します |
| 色 | 等距圏の表示色を指定します |
| 太さ | 線の太さを指定します |
| 線種 | 実線 / 破線 / 点線 から線種を指定します |

地図上をクリックすると、クリックした地点を中心に等距圏が表示されます。

## 方位線 {#azimuth}

方位線の表示／非表示を切り替えます。方位線は、地球が回転楕円球であることを考慮した、指定した地点からの方位を表す線です。

![方位線](/images/azimuth.png)

| 設定項目 | 説明 |
|---|---|
| 距離 | 方位線の長さを指定します（m / km 単位） |
| 間隔 | 方位線の角度間隔を指定します |
| 色 | 方位線の表示色を指定します |
| 太さ | 線の太さを指定します |
| 線種 | 実線 / 破線 / 点線 から線種を指定します |

地図上をクリックすると、クリックした地点を中心に方位線が表示されます。

## 磁北線 {#magnetic-north}

磁北線の表示／非表示を切り替えます。磁北線は、方位磁石の指す北の方向を示す線です。

チェックボックスをオンにすると磁北線が表示され、オフにすると非表示になります。

## 地理院地図で見る

現在表示している場所を地理院地図で開きます。クリックすると、別のウィンドウで地理院地図が表示されます。

## いつもNAVI

現在表示している場所をいつもNAVIで開きます。クリックすると、別のウィンドウでいつもNAVIが表示されます。

## Mapion

現在表示している場所をMapionで開きます。クリックすると、別のウィンドウでMapionが表示されます。

## 場所情報コード

[場所情報コードの説明ページ（国土地理院サイト）](https://www.gsi.go.jp/sokuchikijun/uPlace.html)を開きます。
