# 自分で作る色別標高図

情報リストから「自分で作る色別標高図」を表示します。設定アイコンをクリックしてスタイルを編集できます。

![自分で作る色別標高図](/images/relief-map.png)

## スタイルの編集

| No. | 名称 | 説明 |
|---|---|---|
| ① | リセット | 現在のスタイルを破棄し、読込時の初期状態に戻します。 |
| ② | 標高しきい値入力 | しきい値となる値を入力します。 |
| ③ | 色の選択 | 色を選択します。 |
| ④ | 行の削除 | 行を削除します。 |
| ⑤ | 行の追加 | 標高範囲リストの末尾に行を追加します。 |
| ⑥ | グラデーション | グラデーションを付けます。 |
| ⑦ | 陰影 | 陰影起伏図を利用し陰影を付けます。※日本周辺のみ対応 |
| ⑧ | カラーパターン | カラーパターンから選択します。 |

## 標高タイルの選択

サイドバーの「標高タイル」から、使用する標高タイルを選択できます。なお、標高タイルの選択は地形の立体表示にも影響します。標高タイルの詳細については、[標高タイルの提供](https://maps.gsi.go.jp/development/demtile.html)を参照してください。
