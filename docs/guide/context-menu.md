# コンテキストメニュー

地図の中心地点の情報と、表示している地図のズームレベルを表示します。

![コンテキストメニュー](/images/context-menu.png)

| 項目 | 説明 |
|---|---|
| 住所 | 地図の中心付近の住所です。 |
| 経緯度（度分秒） | 地図の中心の緯度・経度が「度」「分」「秒」単位で表示されます。 |
| 経緯度（十進法） | 地図の中心の緯度・経度が「度」の十進表記で表示されます。 |
| ズーム | 表示している地図のズームレベルです。 |
| UTMポイント | 地図の中心のUTMポイントです。 |
| 標高 | 地図の中心の標高値です。 |

## 情報モードの切替

コンテキストメニューに表示する情報のモードを切り替えられます。

| 設定項目 | 説明 |
|---|---|
| 中心座標モード / クリック地点モード | コンテキストメニューに表示する座標情報を、地図の中心座標とクリックした地点の座標で切り替えます。 |
| 住所表示（漢字 / かな） | コンテキストメニューに表示する住所の表記を、漢字表記とかな表記で切り替えます。 |
