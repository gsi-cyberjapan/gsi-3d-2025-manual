# 検索

住所や地名、経緯度、UTMポイントで検索し、その位置を地図上で表示します。

![検索画面](/images/search.png)

## 検索手順

検索手順は次の通りです。

1. 検索ワード入力ボックスに検索したい住所等を入力し、キーボードの「Enter」キーを押します。
2. 経緯度、UTMポイントの場合、その地点へ地図が移動します。住所・地名の場合は検索結果を表示するダイアログが開きます。
3. 都道府県・市区町村・すべて/居住地名/居住地名以外で絞り込みたい場合はセレクトボックスからそれぞれ選択します。
4. 検索結果の上にマウスを乗せると、その地点のアイコンが変化します。
5. 検索結果をクリックすると、地図の中心がその地点へ移動します。

::: warning
住所で検索した場合、街区レベル(「○○町△丁目□番」)、大字・町丁目レベル、市区町村レベルの代表地点を指す場合があるため、指定した住所の正確な地点を示すとは限りません。
:::

## 経緯度の入力形式

緯度経度の入力は下記の形式に対応しています。

- 緯度・経度を半角スペース区切り、度単位で入力（35.0821 135.193 等）
- 緯度・経度を半角カンマ区切り、度単位で入力（35.0821,135.193 等）
- 緯度・経度をスペース区切り、度分秒で入力（35度1分30秒 135度2分12秒 等）
- 緯度・経度をカンマ区切り、度分秒で入力（35度1分30秒,135度2分12秒 等）

## UTMポイント検索 {#utm}

UTMポイントを入力して検索すると、その地点に直接地図が移動します。（54SUE1234567890 等）
