# 共有

現在表示している地図を共有します。

![共有パネル](/images/share-dialog.png)

| 名称 | 説明 |
|---|---|
| Facebook | 現在表示中の地図のURLをFacebookに投稿します。 |
| X (Twitter) | 現在表示中の地図のURLをXに投稿します。 |
| QRコード | 現在表示している地図URLのQRコードを生成します。※QRコードは株式会社デンソーウェーブの登録商標です。 |
| URLコピー | 現在表示中の地図のURLをクリップボードにコピーします。 |
| サイト埋め込み | 現在表示中の地図をウェブサイトに埋め込むためのHTMLタグを取得します。 |
| メール送信 | 現在表示中の地図のURLをメールで送信します。 |
