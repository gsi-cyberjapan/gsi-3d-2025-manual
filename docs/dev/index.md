# 開発者向けマニュアル

このマニュアルは、本リポジトリをForkして独自の3次元地図可視化サイトを構築する開発者向けのガイドです。

## 対象読者

- 本サイトをベースにカスタムサイトを構築したい開発者
- サイト名やレイヤ構成を変更して独自運用したい方

## ガイド一覧

### [セットアップ](./setup)

開発環境の構築からビルド・デプロイまでの手順を説明します。

- 前提条件（Node.js、pnpm）
- リポジトリのForkとクローン
- 依存パッケージのインストール
- 開発サーバーの起動・本番ビルド

### [サイト名の変更](./site-name)

サイトタイトルやメタ情報をカスタマイズする方法を説明します。

- `src/lib/config.ts` の `GENERAL_CONFIG` の各フィールド
- メタデータが生成される仕組み

### [レイヤの変更](./layers)

ベースレイヤやオプションレイヤの構成を変更する方法を説明します。

- ベースレイヤ（Vector / Raster）の追加・削除・変更
- オプションレイヤの仕組み
- デフォルト表示位置の変更
